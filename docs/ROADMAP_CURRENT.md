## حدود المرحلة الخامسة وشرائحها

المشكلة التي تحلها المرحلة الخامسة هي تنقل اختيار جغرافي واحد بين ثلاثة تمثيلات مستقلة. محرك المسافة الجيوديسية الموجود يبقى متاحًا؛ محرك القياس الشامل ومختبرات الملاحة تبقى في المرحلة السادسة. ذكر routes/time/layers في الخطة الأصلية يعني إعداد عقودها وتمرير الحالة المدعومة، وليس الادعاء بتنفيذ الفلك أو البيانات التي لم تصل مراحلها.

| الشريحة | العمل | معيار قابل للتحقق |
|---|---|---|
| P5.1 | تعريف حالة مشتركة typed: latitude/longitude، ارتفاع عند الحاجة، ID المكان، المصدر والإصدار وتصنيف الإحداثية | اختيار المكان يحفظ الهوية؛ اختيار نقطة حرة لا يحمل اسم مكان سابق |
| P5.2 | adapters مستقلة لـGleason وAE وWGS84 | كل adapter يصرح بمجاله ووحداته وعمليات التحويل؛ لا تبادل لإحداثيات الشاشة |
| P5.3 | مزامنة اختيار البحث والنقر ومؤشر الموقع | تحديث واحد لكل حدث؛ لا حلقات مزامنة أو قفزات اختيار |
| P5.4 | Model Laboratory ومفتش يعرض مدخلات كل نموذج ونتائجه ومصدره | اسم النموذج وإصداره والوحدة والتصنيف ظاهرة مع كل نتيجة |
| P5.5 | عقد المقاييس القابلة للمقارنة | المقادير المختلفة أو غير المعرفة تعرض كغير قابلة للمقارنة، بلا تطبيع يجبر الاتفاق |
| P5.6 | مزامنة التركيز الجغرافي عند الطلب | انتقال الموقع، مع تفسير الاختلاف في التشوه والتكبير بدل فرض مساواة بصرية |
| P5.7 | عرض الفروق للكميات المتجانسة وعقود الزمن/الطبقات/المسارات اللاحقة | فرق عددي فقط عند تطابق المعنى والوحدة والمجال؛ الخدمات غير المنفذة غير متاحة بوضوح |
| P5.8 | حفظ الحالة الضرورية والعمل من الحزم المحلية | إعادة الفتح والاختيار دون شبكة؛ إصدار لعقد الحالة لتطويره لاحقًا |
| P5.9 | اختبارات المزامنة والتراجع والواجهة وOffline | سلامة المراحل 1–4، الحواف والأقطاب وخط ±180°، العربية والإنجليزية والهاتف والمصدر |

ناتج Gleason الحالي بوحدة normalized-radius؛ لا يُحوَّل إلى كيلومترات دون قاعدة مقياس تاريخية موثقة أو افتراض معلن ومفصول. «المسافة بين دولتين» تتطلب تحديد نقطتين/عاصمتين/حدود وطريقة القياس؛ ليست كمية واحدة مفهومة ضمنًا.

## قرار العارض — ADR-014

الاختيار الأصلي ADR-003 كان CesiumJS. المصدر المنفذ في المرحلة الرابعة يستخدم **عارض WebGL2 مخصصًا** وإسقاط SVG ثنائي الأبعاد. وفق م7 يبقى هذا التنفيذ أساس التصحيحات الحالية، وتسجل المخالفة بدل وصفه بأنه Cesium أو استبداله دون تقييم.

- حسابات WGS84 مستقلة عن العارض. الخلفية تستخدم pyproj/PROJ مرجعًا للقبول، والعميل يستخدم GeographicLib JS/proj4js مع بوابة مطابقة.
- العارض الحالي ليس محرك تضاريس أو 3D Tiles، ولا يقدم جودة Cesium كاملة. حدود الرسم الحالية لا تُخفيها تسمية WGS84.
- قبل التضاريس أو البيانات الزمنية/المكانية الثقيلة، تجرى مقارنة موثقة بين الاستمرار في العارض الحالي واستخدام Cesium: حجم التحميل، Offline، تراخيص الأصول، الذاكرة، الهاتف، السياق الرسومي، والدقة.
- النقل إلى عارض آخر، إن اختير لاحقًا، لا يغير العقود الجغرافية أو المحركات العددية. اختيار مكتبة بعينها في المراحل اللاحقة يحتاج تقييمًا وقرارًا، ولم ينفذ هنا.
